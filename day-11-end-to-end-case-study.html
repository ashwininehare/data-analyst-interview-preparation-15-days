🎓 Theory Q&A — 5 Interview Questions
Q1. An interviewer asks: "Why not just do everything in Python? Why use SQL at all?" Answer in 2 sentences with a business reason.
Hired answer: SQL runs inside the database engine — it's faster on millions of rows and avoids pulling raw data over the network. For a bank with 50M transactions, pulling everything into Python would crash memory; SQL lets you aggregate at source and bring only the summary.
Q2. You have SQL output as a CSV. What are the FIRST 3 things you check in Python before any analysis?
Hired answer: (1) df.shape — row/column count matches expected. (2) df.dtypes — dates are datetime, revenue is float, not object. (3) df.isnull().sum() — which columns have NULLs and how many. In BFSI, a NULL in revenue or loan_amount is a data quality red flag, not just a code issue.
Q3. What's the difference between a Pivot Table in Excel and a GroupBy in Python? When do you use which?
Hired answer: Both aggregate data, but Excel Pivot is interactive — drag-and-drop, great for business users to self-serve. Python GroupBy is code-based, reproducible, handles 10M+ rows, and can chain multiple transformations. Use Excel for stakeholder-facing summaries; Python when you need automation, scale, or complex multi-step logic.
Q4. What is a DAX Measure vs a Calculated Column in Power BI? Give one example of each in a banking context.
Hired answer: A Measure is calculated at query time based on filter context — e.g., Total Revenue = SUM(sales[revenue]) — it changes when you filter by region. A Calculated Column is row-level, stored in the model — e.g., Revenue_Band = IF(sales[revenue]>100000,"High","Low"). Use measures for KPIs in visuals; use columns for categorising rows.
Q5. A manager says "your dashboard is beautiful but I don't trust the numbers." What do you do?
Hired answer: I trace back the data lineage — re-run the SQL query, check the Python transformation steps, verify the Excel formula logic, and cross-check the Power BI measure against the raw CSV total. I also do a sense check: does total revenue in Power BI match SELECT SUM(revenue) FROM sales? If any step diverges, that's where the bug is. This is called data reconciliation — critical in BFSI audits.
Task 1 — SQL Extraction (40 min)

🎯 Business Ask

Extract three datasets from persistence_analytics that the Python script and Power BI will consume. Each query has a business justification.

Query 1A — Rep Performance vs Target (JOIN + CASE)

SELECT
    s.rep_name,
    r.team,
    r.target,
    SUM(s.revenue)                                    AS actual_revenue,
    ROUND(SUM(s.revenue) / r.target * 100, 1)         AS pct_of_target,
    CASE
        WHEN SUM(s.revenue) >= r.target THEN 'On Track'
        WHEN SUM(s.revenue) >= r.target * 0.8 THEN 'At Risk'
        ELSE 'Underperforming'
    END                                                AS status
FROM sales s
RIGHT JOIN reps r
    ON s.rep_name = r.rep_name
GROUP BY s.rep_name, r.team, r.target
ORDER BY pct_of_target DESC;

-- RIGHT JOIN → Eve (no sales) appears with NULL revenue → 'Underperforming'
-- Business: HR uses this for performance reviews

Query 1B — Monthly Revenue Trend (Window Function)

SELECT
    DATE_FORMAT(sale_date, '%Y-%m')      AS month,
    region,
    SUM(revenue)                        AS monthly_revenue,
    SUM(SUM(revenue)) OVER (
        ORDER BY DATE_FORMAT(sale_date, '%Y-%m')
        ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
    )                                   AS running_total,
    ROUND(
        SUM(revenue) * 100.0 /
        SUM(SUM(revenue)) OVER (),
    1)                                  AS pct_contribution
FROM sales
GROUP BY DATE_FORMAT(sale_date, '%Y-%m'), region
ORDER BY month;

-- Business: identifies which months drove most revenue (seasonality)

Query 1C — Product Revenue Ranking (CTE + RANK)

WITH product_summary AS (
    SELECT
        product,
        COUNT(*)          AS num_deals,
        SUM(revenue)      AS total_revenue,
        AVG(revenue)      AS avg_deal_size
    FROM sales
    GROUP BY product
),
ranked AS (
    SELECT *,
        RANK() OVER (ORDER BY total_revenue DESC) AS revenue_rank
    FROM product_summary
)
SELECT * FROM ranked
ORDER BY revenue_rank;

-- Business: portfolio mix — which products drive volume vs value

Task 2 — Python EDA in Jupyter (40 min)

🎯 Business Ask

Load the SQL exports, validate data quality, run EDA, and produce 3 business insights for the Regional Head.

Step 2A — Load & Validate

import pandas as pd
import numpy as np

# Load all 3 exports
rep_df   = pd.read_csv('rep_performance.csv')
trend_df = pd.read_csv('monthly_trend.csv')
prod_df  = pd.read_csv('product_rank.csv')

# ── Data Audit ──────────────────────────────
for name, df in {'rep': rep_df, 'trend': trend_df, 'product': prod_df}.items():
    print(f"\n── {name} ──")
    print(df.shape)
    print(df.dtypes)
    print(df.isnull().sum())

# Fix: fill NULL revenue for Eve (no sales → 0)
rep_df['actual_revenue'] = rep_df['actual_revenue'].fillna(0)
rep_df['pct_of_target']  = rep_df['pct_of_target'].fillna(0)
rep_df['status']         = rep_df['status'].fillna('Underperforming')

Step 2B — EDA & Business Insights

# ── Insight 1: Who is underperforming? ──────
under = rep_df[rep_df['status'] == 'Underperforming']
print(f"Underperforming reps: {len(under)} out of {len(rep_df)}")
print(under[['rep_name', 'team', 'actual_revenue', 'pct_of_target']])

# ── Insight 2: Revenue concentration ────────
top2_revenue = rep_df.nlargest(2, 'actual_revenue')['actual_revenue'].sum()
total        = rep_df['actual_revenue'].sum()
print(f"Top 2 reps drive {top2_revenue/total*100:.1f}% of revenue — key-person risk")

# ── Insight 3: Product mix ───────────────────
loan_rev    = prod_df[prod_df['product']=='Loan']['total_revenue'].values[0]
total_rev   = prod_df['total_revenue'].sum()
print(f"Loan products = {loan_rev/total_rev*100:.1f}% of total revenue")

# ── Summary stats ────────────────────────────
print("\n── Rep Performance Summary ──")
print(rep_df.groupby('status')['actual_revenue'].agg(['count', 'sum', 'mean']).round(0))

# ── Export cleaned data for Excel ────────────
rep_df.to_csv('rep_performance_clean.csv', index=False)
print("Saved rep_performance_clean.csv")

Step 4B — DAX Measures

-- Measure 1: Total Revenue
Total Revenue = SUM(sales[revenue])

-- Measure 2: % of Target (whole team)
% of Target =
DIVIDE(
    SUM(sales[revenue]),
    SUM(reps[target]),
    0
)

-- Measure 3: Revenue Rank (for table visual)
Revenue Rank =
RANKX(
    ALL(reps[rep_name]),
    [Total Revenue],
    ,
    DESC
)

-- Measure 4: Running Total (line chart)
Running Revenue =
CALCULATE(
    [Total Revenue],
    FILTER(
        ALL(sales[sale_date]),
        sales[sale_date] <= MAX(sales[sale_date])
    )
)
