⏱ SQL Round — 40 Minutes · 30 Points · 3 Queries

⏰ Rules: Start timer. No hints. No notes. Submit all 3 or lose partial credit.

SQL Q1 · Easy · 10 pts · Suggested time: 10 min
Write a SQL query that returns each rep's name, team, total revenue, and their rank by revenue (1 = highest). Include reps with no sales. Show results ordered by rank.
Scoring: LEFT JOIN (2) · SUM with COALESCE (2) · RANK() OVER (3) · ORDER BY rank (1) · Aliases (2)
Model Answer: 
SELECT
    r.rep_name,
    r.team,
    COALESCE(SUM(s.revenue), 0)              AS total_revenue,
    RANK() OVER (ORDER BY COALESCE(SUM(s.revenue),0) DESC) AS revenue_rank
FROM reps r
LEFT JOIN sales s ON r.rep_name = s.rep_name
GROUP BY r.rep_name, r.team
ORDER BY revenue_rank;
-- 5 rows. Eve: revenue=0, rank=5
SQL Q2 · Medium · 10 pts · Suggested time: 15 min
Write a SQL query using a CTE to find the product with the highest average deal size, AND show what percentage of total revenue it contributes. Return: product, avg_deal_size, total_revenue, pct_of_grand_total.
Scoring: CTE correct (2) · AVG + SUM (2) · Grand total subquery/window (3) · ROUND + % calc (2) · Readable aliases (1)
Model Answer: 
WITH product_stats AS (
    SELECT
        product,
        ROUND(AVG(revenue), 0)   AS avg_deal_size,
        SUM(revenue)             AS total_revenue
    FROM sales
    GROUP BY product
)
SELECT
    product,
    avg_deal_size,
    total_revenue,
    ROUND(total_revenue * 100.0 /
          (SELECT SUM(revenue) FROM sales), 1) AS pct_of_grand_total
FROM product_stats
ORDER BY avg_deal_size DESC;
-- Insurance avg = 97,500 (highest); Loan = 54.1% of total
SQL Q3 · Hard · 10 pts · Suggested time: 15 min
Using a CTE and window function, write a query that shows for each sale: the rep's name, region, revenue, the running total revenue ordered by sale_date, and the revenue as a % of that running total. Also add a flag: 'Above Avg' if revenue > overall average, else 'Below Avg'.
Scoring: CTE or subquery (1) · Running total window (3) · % of running total (2) · Overall AVG subquery (2) · CASE WHEN flag (2)
Model Answer: 
SELECT
    rep_name,
    region,
    revenue,
    sale_date,
    SUM(revenue) OVER (
        ORDER BY sale_date
        ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
    )                                             AS running_total,
    ROUND(
        revenue * 100.0 /
        SUM(revenue) OVER (
            ORDER BY sale_date
            ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
        ), 1
    )                                             AS pct_of_running_total,
    CASE
        WHEN revenue > (SELECT AVG(revenue) FROM sales)
            THEN 'Above Avg'
        ELSE 'Below Avg'
    END                                           AS avg_flag
FROM sales
ORDER BY sale_date;
-- AVG = 90,833. Above: Alice(120K,110K), Carol(95K) · Below: Bob(85K,75K), Dave(60K)

import pandas as pd
import numpy as np

# ── STEP 1 (5 pts): Load + Full Data Audit ──────────────────────
df = pd.read_csv('sales.csv')
df['sale_date'] = pd.to_datetime(df['sale_date'])
print("Shape:", df.shape)          # (6, 6)
print(df.dtypes)
print(df.isnull().sum())
print(df.describe().round(0))

# ── STEP 2 (5 pts): Revenue by Product + % contribution ─────────
prod = df.groupby('product')['revenue']\
         .agg(['sum','mean','count']).reset_index()
prod.columns = ['product','total_rev','avg_rev','deals']
prod['pct'] = (prod['total_rev']/prod['total_rev'].sum()*100).round(1)
print(prod.sort_values('total_rev', ascending=False))

# ── STEP 3 (5 pts): Rep performance vs target ───────────────────
reps = pd.read_csv('reps.csv')
merged = df.groupby('rep_name')['revenue'].sum().reset_index()
merged = reps.merge(merged, on='rep_name', how='left')
merged['revenue'] = merged['revenue'].fillna(0)
merged['pct_target'] = (merged['revenue']/merged['target']*100).round(1)
merged['status'] = merged['pct_target'].apply(
    lambda x: 'On Track' if x>=100 else ('At Risk' if x>=80 else 'Underperforming'))
print(merged[['rep_name','team','target','revenue','pct_target','status']])

# ── STEP 4 (5 pts): Outlier Detection (Z-score) ─────────────────
df['z_score'] = ((df['revenue'] - df['revenue'].mean())
                 / df['revenue'].std()).round(2)
outliers = df[df['z_score'].abs() > 1.5]
print(f"Outliers: {len(outliers)}")
print(outliers[['rep_name','product','revenue','z_score']])

# ── STEP 5 (5 pts): 3 Business Insights (YOU must write these) ──
total = df['revenue'].sum()
top_rep = merged.loc[merged['revenue'].idxmax(), 'rep_name']
top_rev = merged['revenue'].max()
under   = merged[merged['status']=='Underperforming']
print(f"""
── Business Insights ────────────────────────────────
1. REVENUE CONCENTRATION: {top_rep} = {top_rev/total*100:.1f}% of ₹{total:,.0f} total.
   Risk: Key-person dependency. Recommend cross-training backup rep.

2. UNDERPERFORMANCE: {len(under)} of {len(merged)} reps below 80% target
   ({', '.join(under.rep_name.tolist())}). Retail team churn risk.
   Action: Weekly check-in + incentive review for underperformers.

3. PRODUCT MIX: Loan dominates at {prod.loc[prod.product=='Loan','pct'].values[0]:.1f}%.
   Credit risk concentration. Recommend Insurance push (avg deal = ₹97,500,
   same revenue, lower default risk than Loan).
""")
